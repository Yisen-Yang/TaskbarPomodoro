01 · DESIGN SYSTEM

设计语言：暖光玻璃

以「番茄暖光」为视觉核心：深色玻璃底 + 珊瑚橙渐变 + 细腻高光描边。所有页面共用一套圆角、间距、色彩与组件规范，避免每个窗口各做各的。

① 状态用颜色区分，不用文字堆砌

专注=橙红、短休息=绿、长休息=紫、暂停=降透明度、锁定=强调色描边。一眼可辨。

② 同一动作在任何页面长得一样

「开始/暂停」「重置」「锁定」图标与位置在主窗口、右键菜单、托盘菜单保持一致。

③ 切换主题不打断计时

主题只作用于视觉层，不触碰计时状态与 deadline —— 这是必须守住的底线。
